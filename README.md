### 🚀 触发构建

`Actions` → `Build Windows 7` → `Run workflow`

| 字段 | 填写内容 |
|:---|:---|
| `version` | 版本号，去掉开头的 `v`，如 `1.14.0-reF1nd.1` |
| `source_ref` | tag 页里对应版本的完整名，如 `v1.14.0-reF1nd.1` |
| `create_release` | 测试不勾，正式发布勾选 |
